# NO MORE SILENCE — React Frontend Prototype

A responsive React + Vite frontend based on the supplied concept note for a proposed gender justice and violence-prevention digital initiative.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Included screens

- Overview dashboard
- Safe Help flow (local-only demo interaction)
- Emergency contacts / SOS information
- Know Your Rights learning cards
- Find Support with search
- Legal Support information
- Psychosocial Support
- Institutional Reporting demo flow

## Important prototype notes

- This is a frontend prototype. It does not send reports, store case data, provide live SOS dispatch, or connect users to counsellors.
- The uploaded BRAC logo image is used as a supplied visual asset. This does not imply that this prototype is an official BRAC product or has been approved by BRAC.
- Emergency contact numbers are presented for prototype reference. Re-check all numbers, service scope, operating hours, legal information, safeguarding requirements, and BRAC approvals before public deployment. The reference URLs for contact numbers are listed in `SOURCES.md`.
- Do not collect or transmit sensitive information until a privacy, safeguarding, security, referral, consent, and retention framework has been reviewed.

## Language switcher

Use the language control in the top-right header to switch between Bangla and English. The prototype translates the visible UI copy and labels locally; changing languages does not send user data to a server. Form values remain stable when the display language changes. The language menu closes on outside click or Escape.

## Prototype boundaries

Language switching, navigation, local demo forms, local search/filtering, and in-page feedback are frontend interactions only. Live complaint submission, secure case management, real-time SOS dispatch, location sharing, and counselling/referral workflows require approved backend services and safeguarding/security review.
